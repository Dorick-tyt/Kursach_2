# Aeroplane Tracker
## Система отслеживания самолётов в воздушном пространстве различных стран

## Описание
**Aeroplane Tracker** — это программа для получения и анализа информации о самолётах, находящихся в воздушном пространстве выбранной страны. Программа использует публичные API для получения координат стран и данных о самолётах в реальном времени.

### Основные возможности:

- **Поиск самолётов** в воздушном пространстве любой страны
- **Топ N самолётов** по высоте и скорости
- **Фильтрация** по стране регистрации
- **Фильтрация** по диапазону высот и скоростей
- **Статистика** по всем обнаруженным самолётам
- **Сохранение** данных в JSON файл
- **Загрузка** ранее сохранённых данных

## Особенности

| Функция | Описание |
|---------|----------|
| **Реальный API** | Использует OpenSky Network для получения актуальных данных |
| **Тестовый режим** | Работа без интернета с демо-данными для отладки |
| **Красивый вывод** | Табличное отображение информации о самолётах |
| **Обработка ошибок** | Автоматические повторные попытки при сбоях |
| **Модульная структура** | Легко расширяется и модифицируется |
